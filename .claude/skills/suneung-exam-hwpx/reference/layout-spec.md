# 수능 수학 영역 문제지 양식 실측값

2026학년도 수능 수학 영역 문제지(평가원 공개 PDF, A3 842×1191 pt)를 PyMuPDF로 잰 값이다.
`tools/build.py` 상단 상수가 이 값을 그대로 쓴다. 단위 pt (1 pt = 100 HWPUNIT).

## 쪽 구성
- 공통(수학Ⅰ·Ⅱ) 8쪽 + 선택과목(확률과 통계 / 미적분 / 기하) 각 4쪽 = 20쪽.
- 머리말 쪽 번호는 과목별로 1부터 다시 센다(선택과목 첫 쪽이 다시 1). 꼬리말 `n/20` 은 전체 쪽 번호.
- 홀수 쪽: 왼쪽 `홀수형` 상자 + 오른쪽 큰 쪽 번호. 짝수 쪽: 왼쪽 쪽 번호 + 오른쪽 `홀수형`.
- 과목 첫 쪽: 큰 제목 블록(107.8–218.3). 원본도 흰 바탕 표로 머리말을 덮는 방식이다.
