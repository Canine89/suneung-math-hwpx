# 한글 수식 스크립트 요약 (problems/exam.py 의 $...$ 안)

LaTeX가 아니다. 공백은 무시되므로 띄어쓰기는 `~`(보통), `` ` ``(1/4칸).

| 표현 | 스크립트 |
|---|---|
| 분수 | `{a} over {b}` |
| 제곱근 | `sqrt {3}` |
| 위·아래 첨자 | `x ^{2}`, `a _{n+1}` |
| 극한 | `lim _{h -> 0}` , `lim _{theta -> 0+}`, `inf` |
| 합 | `sum _{k=1} ^{10}` |
| 적분 | `int _{0} ^{3} f(x)dx` |
| 곱, 점곱 | `TIMES`, `cdot` |
| 부등호 | `<=`, `>=`, `!=`, `<`, `>` |
| 괄호(크기 자동) | `left ( ... right )`, `left | ... right |` |
| 중괄호 문자 | `left lbrace a _{n} right rbrace` |
| 경우 나누기 | `cases{x ^{3} -a & (x<2)#ax+2 & (x >= 2)}` |
| 수식 안 한글 | `"이"~"홀수인"~"경우"` (따옴표 안 공백은 사라지므로 `~`로 잇는다) |
| 선분, 벡터, 각 | `overline {rm AB}`, `vec {rm PA}`, `angle rm BAC` |
| 정체(점 이름, P, E, V, N, B) | `rm A` → 빌드가 자동으로 `rm A it` 로 바꿔 뒤 글자를 다시 이탤릭으로 |
| 그리스 문자 | `pi`, `theta`, `alpha`, `sigma` |
| 함수 이름 | `sin`, `cos`, `tan`, `log _{2} x`, `ln`, `e ^{x}` (자동 정체) |
| 미분 | `f'(x)` |
| 화살표 | `->` |

## 수능식 표기 습관
- 숫자 하나도 수식으로: `$1$보다 큰`, `$3$개`.
- 조건이 여러 개면 수식을 나눈다: `$a _{1} =2$, $a _{5} =4a _{3}$` (줄바꿈 가능해져 양쪽 정렬 벌어짐 방지).
- 수식 뒤 조사는 붙여 쓴다: `$f(x)$에 대하여`.
- 확률·통계 기호: `{rm P} left ( X <= 10 right )`, `{rm E} left ( X right )`, `{rm N} left ( m,~2 ^{2} right )`.
- 경우 나누기는 빌드가 두 줄 사이에 빈 줄을 넣어 원본처럼 큰 중괄호로 만든다.
