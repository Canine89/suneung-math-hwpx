## 공통 규칙 (대학수학능력시험 문제지 그림 스타일)

- **출력 형식**: PNG, **600 dpi**, 흰색 배경(투명 X), 그림 바깥 여백 거의 없이(약 1 mm) 잘라내기.
  - 가능하면 같은 이름의 SVG도 함께 저장 (예: `fig_c07.svg`). 단, 필수는 PNG.
- **실제 인쇄 크기**: 각 그림에 적힌 `가로 폭(mm)`에 맞춰 figsize를 잡아 주세요. (600dpi × mm/25.4 = 픽셀 폭)
  - 문제지는 A3 2단 편집이고 한 단의 폭은 약 112 mm입니다.
- **선**: 검은색 단색. 곡선·도형 선 굵기 0.6 pt, 좌표축 0.5 pt. 점선은 0.5 pt, 짧은 간격.
- **색칠한 영역**: 연한 회색(#D9D9D9) 단색, 테두리 없음.
- **좌표축**: 양 끝 중 양의 방향에만 작은 채운 화살촉. 축 이름 `x`, `y`는 화살촉 근처에 이탤릭.
  눈금, 격자, 눈금 숫자 **없음**. 원점은 축 교점 왼쪽 아래에 정체 `O`.
- **글꼴**: 수능 수식 글꼴과 맞추기 위해 `C:\Windows\Fonts\HYHWPEQ.TTF`(한컴 수식 글꼴) 사용을 권장.
  없으면 Times New Roman. 크기는 **인쇄 기준 10 pt**.
  - 변수·식(x, y, y=f(x), θ 등)은 *이탤릭*, 점 이름(A, B, C, O, P, H …)은 정체(로만).
  - 식 라벨은 수능처럼 `y = x² − 2x` 형식(등호 앞뒤 공백, 마이너스는 − 기호).
- **점**: 지름 약 1.2 mm 채운 검은 점은 문제에서 '점'으로 이름 붙인 위치에만. 교점·원점에는 찍지 않음.
- 제목, 범례, 테두리 상자 **없음**. 장식 없이 수능 문제지와 똑같이 담백하게.

## fig_c07.png — 공통 7번 (가로 60 mm)

문제: 곡선 y = x² − 2x 와 직선 y = x 로 둘러싸인 부분의 넓이는?

- 좌표평면, 표시 범위 대략 x ∈ [−1, 4], y ∈ [−1.5, 4.5] (비율 1:1 아니어도 됨, 보기 좋게).
- 포물선 y = x² − 2x (x ∈ [−0.6, 3.4] 정도), 직선 y = x (x ∈ [−0.8, 4]).
- 두 그래프가 둘러싼 영역(0 ≤ x ≤ 3, x² − 2x ≤ y ≤ x)을 연한 회색으로 칠함.
- 라벨: 포물선 오른쪽 위 끝 근처에 `y = x² − 2x`, 직선 위쪽 끝 근처에 `y = x`, 원점 `O`, 축 `x`, `y`.
- 교점 (3, 3)에 점선으로 x축에 수선을 내리고 x축 아래에 `3` 표시.

## fig_c10.png — 공통 10번 (가로 70 mm)

문제: 0 ≤ x ≤ 2π/b 에서 정의된 함수 f(x) = a sin bx (a > 0, b > 0). 곡선 y = f(x)와
직선 y = a/2 가 만나는 두 점 A, B, 함수 f(x)가 최솟값을 갖는 점 C. 삼각형 ABC.

- 실제 값 a = 6, b = π/6 기준으로 그리되, 눈금 숫자는 표시하지 않음.
  곡선: x ∈ [0, 12], y = 6 sin(πx/6).
- 직선 y = 3 (x ∈ [−0.5, 12.5])을 실선으로, 오른쪽 끝에 `y = a/2` 라벨 (a/2는 분수 꼴 또는 `a/2`).
- A = (1, 3), B = (5, 3), C = (9, −6). 삼각형 ABC를 실선으로 그리고 내부를 연한 회색으로 칠함.
- 점 A, B, C에 점을 찍고 이름 표시(A는 왼쪽 위, B는 오른쪽 위, C는 아래).
- 곡선 오른쪽 끝 근처에 `y = f(x)` 라벨. 원점 `O`, 축 `x`, `y`.

## fig_c14.png — 공통 14번 (가로 55 mm)

문제: AB = 6, AC = 4, cos(∠BAC) = 1/3 인 삼각형 ABC (BC = 6, 즉 AB = BC인 이등변삼각형)와 그 외접원.
점 A를 포함하지 않는 호 BC 위의 점 D에 대하여 BD = CD. 사각형 ABDC.

- 외접원(반지름 9√2/4 ≈ 3.18)을 실선으로.
- 꼭짓점: B를 왼쪽 아래, C를 오른쪽 아래쯤 두되, 실제 길이 비율(AB=6, AC=4, BC=6)을 정확히 지킬 것.
  A는 원 위쪽, D는 BC 아래쪽 호의 중점.
- 선분 AB, AC, BC, BD, CD 를 실선으로. (색칠 없음)
- 점 이름 A, B, C, D (원 바깥쪽에 배치).

## fig_m26.png — 미적분 26번 (가로 60 mm)

문제: 곡선 y = √x · eˣ 와 x축 및 직선 x = 1 로 둘러싸인 부분을 밑면으로 하는 입체도형.
이 입체도형을 x축에 수직인 평면으로 자른 단면이 모두 정사각형이다.

- 수능 단골 '단면이 정사각형인 입체' 그림: 비스듬한 투시(사선 투영)로 xy평면을 바닥에 눕혀 그림.
- 바닥: 곡선 y = √x eˣ (0 ≤ x ≤ 1), x축, 직선 x = 1.
- 바닥 곡선 위의 각 점에서 위로 선 정사각형 단면들이 이루는 입체의 윤곽선(위쪽 모서리 곡선, x = 1 의 정사각형 단면)을 실선, 가려진 선은 점선.
- 중간 지점 하나(x ≈ 0.6)의 정사각형 단면을 연한 회색으로 칠해서 강조.
- 라벨: `O`, `x`, `y`, `1`(x = 1 위치), 곡선 옆 `y = √x eˣ`.

## fig_m29.png — 미적분 29번 (가로 55 mm)

문제: 반지름 2, 중심각 π/2인 부채꼴 OAB. 호 AB 위의 점 P (∠POA = θ).
점 P에서의 접선이 직선 OA와 만나는 점 T, 점 P에서 선분 OA에 내린 수선의 발 H.
S(θ) = 선분 AT, 선분 TP, 호 PA로 둘러싸인 부분의 넓이, T(θ) = 삼각형 PHA의 넓이.

- 좌표축 없이 도형만. O를 왼쪽 아래, A를 오른쪽(OA 수평), B를 위쪽.
- 그릴 때 θ = 35° 정도로.
- 부채꼴(선분 OA, OB, 호 AB) 실선. 선분 OP 실선, 선분 OT(OA 연장) 실선, 접선 PT 실선, 선분 PH 실선.
- S(θ) 영역(호 PA, 선분 AT, TP 사이)을 연한 회색으로, 삼각형 PHA는 빗금 또는 조금 더 진한 회색(#BFBFBF)으로 구분.
- 각 θ를 O에 작은 호로 표시하고 `θ` 라벨. 점 O, A, B, P, H, T 라벨.
