# 샘플 문제지

이 스킬로 만든 수능형 수학 영역 모의 문제지 3개 회차입니다. 새 문제지를 만들 때 형식·난이도·그림 요청 방법의 참고로 씁니다.

| 회차 | 특징 |
|---|---|
| `2027-모의1` | 첫 회차. 원본 수능 배치 그대로(1·2 / 3·4, 5·6 / 7 …). 그림 7개 |
| `2027-모의2` | 쪽 격자 배치로 전환, 문항 넘침 자동 검사. 그림 8개(c10은 가이드 참조 방식으로 재작성) |
| `2027-모의3` | 2쪽 2×2, 3쪽 1×2 배치. 그림 8개 모두 가이드 참조 image gen |

각 회차 폴더
- `problems/exam.py` 문항 데이터, `problems/verify.py` 정답 계산 검증
- `figures/` 최종 그림(PNG, 600 dpi), `FIGURE_SPEC.md`(Codex 요청서), `DONE.txt`(Codex 검수 기록),
  `src/`(image gen 프롬프트·가이드 스크립트 — 생성 원본 이미지는 용량 때문에 저장소에서 제외)
- `output/` 결과 hwpx·pdf·정답표

## 다시 만들기
회차 폴더의 `problems/`, `figures/` 를 프로젝트 루트의 `problems/`, `figures/` 로 복사한 뒤 `python tools/build.py`.
