- **색칠**: 연한 회색 #D9D9D9 단색(두 영역을 구분할 때만 더 진한 #BFBFBF 추가), 테두리 없음.

  (아래에 따로 적은 값 라벨만). 원점은 교점 왼쪽 아래 정체 `O`.
- **글꼴**: 수식체 느낌의 세리프(Times 계열). 인쇄 기준 약 10 pt.

- **점**: 문제에서 이름 붙인 점만 지름 약 1.2 mm 검은 점.
- 제목·범례·테두리 상자 **없음**. 수능 문제지처럼 담백하게.

## fig_c08.png — 공통 8번 (가로 55 mm)
문제: 곡선 y = x² − 2x 와 직선 y = 2x 로 둘러싸인 부분의 넓이.
- 표시 범위 대략 x ∈ [−1, 5], y ∈ [−1.5, 9.5]. 포물선 꼭짓점 (1, −1), 원점과 (2, 0)에서 x축과 만남.
- 직선 y = 2x 는 원점과 (4, 8)을 지남. 두 그래프의 교점은 (0, 0), (4, 8).
- 0 ≤ x ≤ 4 에서 포물선과 직선 사이 영역을 연회색으로 칠함(x축 아래로 내려간 부분 포함).
- (4, 8)에서 x축으로 점선 수선, x축 아래에 `4`.
- 라벨: 포물선 오른쪽 위 끝 `y = x² − 2x`, 직선 위쪽 끝 `y = 2x`, `O`, `x`, `y`.

## fig_c10.png — 공통 10번 (가로 65 mm)
문제: 0 ≤ x ≤ 8 에서 y = 3 sin(πx/4) 의 그래프와 직선 y = k, y = −k (0 < k < 3).
- 실제 값: k = 3√2/2 ≈ 2.12. 곡선은 (0,0)에서 시작, 최댓점 (2, 3), x절편 (4, 0), 최솟점 (6, −3), (8, 0)에서 끝.
- A = (1, k), B = (3, k) — y = k 와 곡선의 교점. C = (5, −k), D = (7, −k) — y = −k 와 곡선의 교점.
  **x 간격이 A–B 2, B–C 2, C–D 2 로 모두 같아야 함.**
- 직선 y = k, y = −k 를 x ∈ [−0.3, 8.5] 로 실선, 오른쪽 끝에 각각 `y = k`, `y = −k`.
- 사각형 ABDC(평행사변형: A→B→D→C→A)를 실선으로 그리고 내부 연회색.
- 점 A, B, C, D 표시(A·B는 위, C·D는 아래). 곡선 끝 근처 라벨 없음. `O`, `x`, `y`.
